# 镜头语法：节奏、构图、转场

## 时间单位

- 24 fps，默认 120 BPM → 1 拍 = 12 帧，半拍 = 6 帧。
- 镜头时长只用 6 / 12 / 18 / 24 帧，切点就会落在节拍上（audio.py 在每拍放 kick，每个切点放一个 blip）。
- 15 秒 = 360 帧，大约 25–28 个镜头。

## 推荐结构（15 秒）

| 段落 | 帧 | 内容 |
|---|---|---|
| 开场 | 0–11 | 品牌字母卡片逐个砸下（`intro` 预设，k≈2.4） |
| 倒数 / 引子 | 12–29 | 3 个 6 帧镜头：大数字 + 照片条（`countdown()`） |
| 主体展示 | 30–140 | 10 个 12 帧镜头：主角登场、开箱、照片拼贴、网格、特写 |
| 大字段 | 140–275 | 立体大字（`jump`）、中文大字抖动（`tiao`）、跑马灯、贴纸雨、涂鸦墙、线稿 |
| 冲击 | 264–275 | 印章砸下 + 震屏（`stamp`） |
| 闪回 | 276–299 | 24 帧，每 2 帧切一个前面的镜头，叠 VOL.01 字样，后半段每 4 帧白闪 |
| 高潮 | 300–317 | 主角起飞 / 大字标语 |
| 结尾 | 318–359 | Logo lockup + 标语 + 小角标，停住 |

## 镜头内部节奏

- 第 0 帧：底色和主图层已经在画面里（不要从空白开始）。
- 第 1–4 帧：主要元素用 `eBack` 弹入（3–5 帧完成）。
- 第 3–8 帧：第二层（贴纸、标签、大字）进场。
- 12 帧的镜头里可以在第 6–7 帧"切内容"（换一张图），会显得更快，比如 cateye、reflex 两个镜头。
- 一直在动的东西（旋转的光芒、滚动的条纹、照片缓慢推近、颗粒感）保证没有一帧是静止的。

## 画面规则

- 舞台 1000×1000。安全区：左下角 (0–160, 930–1000) 是时间码，右上角 (790–980, 20–90) 是品牌角标。
- 拼贴层次（从下到上）：纯色或照片底 → 半调 / 光芒 / 新闻纸纹理 → 撕纸照片卡（`photoCard`，带阴影）→ 主角（贴纸白边）→ 大字 / 贴纸 / 胶带 → 颗粒和暗角（引擎自动加）。
- 每个镜头最多 3 个颜色加黑白。底色轮换顺序参考：米白 → 红 → 黄 → 青 → 黑色星空 → 绿。
- 文字：英文用 900 字重的展示字体，可以斜体、立体（`extruded`）、描边；中文用 CJK 900 字重，加白描边和黑色投影。

## 转场

- 默认：硬切 + 第 0 帧 18% 白闪（引擎自动加）。
- `punch: true`：切入时从 1.09 倍推到 1.0 倍（4 帧）。大部分镜头都可以开。
- `trans: 'tear'`：上一个镜头被撕纸从右往左扫走（5 帧）。全片最多 4 次，配 whoosh 音效（自动加）。
- 退场模糊：`jump` 预设里的 `exit("left", blur=24)` 做法：`g.filter = blur(...)` 加位移。

## 修改时的对应关系

| 用户说 | 改什么 |
|---|---|
| "太慢 / 拖" | 减少 `dur`，提高预设的 `k`，在镜头内加第二层元素 |
| "素材太少 / 太单调" | 加照片层（`photoCard` / `fullCover`），叠 `tape` / `sticker` / `emoji`，镜头中途换图 |
| "第 N 个镜头换颜色" | 改该镜头的 `g.fillStyle` 或 `CONFIG.palette` |
| "文字改成 X" | 预设镜头改 opts，自定义镜头改字符串 |
| "节奏对不上音乐" | 确认所有 `dur` 都是 6 的倍数，调整 `CONFIG.bpm` |
